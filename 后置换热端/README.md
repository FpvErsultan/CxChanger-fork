# 后置换热端项目

本目录收录后置换热端/停靠坞项目的网格模型与运动参数。安装或执行运动前，请先核对模型版本、安装方向、机器坐标系及可用行程。

## 文件

- [完整修复版 STL 模型](后置换热端完整全套%20修复版本.stl)：STL 网格模型不含参数化特征树，不能像 STEP 一样直接编辑尺寸。
- [停靠坞运动参数](dock_motion_parameters.txt)：原始 Klipper 参数片段。
- [English guide](README_EN.md)：英文版说明。

## 参数说明

| 参数 | 值 | 作用 |
|---|---:|---|
| variable_dock_shift_x | 3 | X 方向横移，用于打开或闭合挤出机夹臂。 |
| variable_dock_dodge_y | -14 | Y 方向相对避让位移。 |
| variable_dock_safe_y | -30 | Y 方向安全拔出停靠坞的相对位移。 |

数值沿用提供的原始配置。原文未注明坐标基准、关联宏名称或适用机型；请结合实际 Klipper 宏核对方向、单位和运动顺序。此参数片段不是可单独加载的完整 printer.cfg 或宏文件。

## 集成与安全调试

1. 备份现有配置，找到实际读取这些变量的停靠/换头宏，再把参数放入该宏对应的变量定义处。
2. 检查坐标方向、行程边界、停靠位置与周围净空，确认不会撞到机架、打印头、线束或其他热端。
3. 在打印之外低速逐步验证方向和避让顺序，手边准备好停止运动；确认路径无碰撞后，再进行完整停靠测试。
4. 调整后按 Klipper 的正常流程重新加载配置，并复核所有换头路径。

若发生碰撞、卡滞或运动方向不符，立即停止并检查坐标系、变量引用和路径净空。不要仅通过增大位移来掩盖原因。

## 模型使用

使用前检查 STL 的单位、比例、网格完整性和安装方向，并结合目标打印机确认兼容性。当前资料没有给出尺寸公差、打印材料、切片参数或完整宏，这些内容需要根据实际结构单独验证。
